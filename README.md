# 📊 Market Research Dashboard

Interactive swing trading analysis system with real-time signals and macro context.

## 📈 Features
- Live market prices (Gold, Bitcoin, NASDAQ, Oil)
- Macro indicators (DXY, Treasury yields, yield curve)
- 35+ trading signals (BUY/SELL)
- Economic calendar with dates
- Interactive charts (Yield curve analysis)
- Daily WhatsApp/Telegram alerts

## 🔗 Dashboard
[Open Dashboard](dashboard.html)

## 📱 Daily Updates
Automated daily messages via Telegram at 9:00 AM with:
- Market prices
- Trading signals
- Macro analysis
- Economic calendar
- Link to full dashboard

## 🛠️ Tech Stack
- Python 3.x
- yfinance (market data)
- Telegram Bot API
- HTML5/Chart.js (dashboard)

## 📁 Files
- dashboard.html - Interactive dashboard
- send_whatsapp_update.py - Daily alert sender
- data/ - Historical market data
